# 光影统一 · 声轨编排 · 节奏紧凑

针对 2026-11-21 洛阳桥 50 秒成片暴露的三个问题，逐条给可执行的写法。三节都能直接复制进 prompt。

---

## 一、光影统一：给「光照卡」，逐段原样复制

### 问题现象

同一片子里前 3 拍冷青、后 2 拍日落暖金，明暗来回跳。看起来像两天拍的素材拼在一起。

### 根因

旧 prompt 只在开头写了 `【风格锚】`，里面只有画风（国风写实、厚涂油画、影视级布光），**没有一句约束光照条件**。Muse 拆段生成时，每段独立决定光照，风格锚管不住它。

`style` 参数同理 —— `style` 是画风，不是光照。

### 解法：光照卡（Lighting Card）

**在 prompt 顶部固定一段，每段一字不改复制。**拆段时每段都会读到它，等于给所有段发了同一张灯位图。

```
【光照卡·全片唯一，任何镜头不得偏离】
时段：正午前三刻（太阳仰角约 50°）
色温：5600K 冷白，不偏黄不偏蓝
主光：自左前上方 45° 射入，光比 1:4，硬光
投影：短、边缘清晰、方向统一指向右后方
天空：灰白偏冷，云层薄而均匀，无对流云、无晚霞
水面：受光面亮银白，背光面深灰绿
铁律：全片所有镜头共用这一套光照。光线方向、强度、色温、云层厚度、阴影长度、曝光水平逐段完全一致。
禁止：明暗起伏、曝光跳变、色温漂移、天色由冷转暖或由明转暗、光斑游移、丁达尔光柱忽强忽弱、镜头之间出现不同的天色。
```

要点：

1. **必须给具体数值区间**（色温 K 数、光比、太阳仰角）。只写「光线统一」模型不认，写「5600K、1:4、仰角 50°」才当硬约束。
2. **必须列「禁止」清单**，把上一次实际发生的偏移写进去（冷转暖、明转暗）。
3. **时段要避开过渡光**。日出、日落、黄昏是光照变化最快的时段，模型最爱在这里自由发挥。要稳定就选**正午硬光**（最不容易变）或**阴天柔光**（最没有方向性）。要氛围改在色温上调，别改时段。
4. 叙事需要跨时间（「六年之后」），**不要让画面承担时间流逝**，用旁白一句话交代。画面一变光，观众第一反应是穿帮，不是时间流逝。

### 兜底：后期按段匹配（0 成本）

万一仍然漂了，用 ffmpeg 按段做统计匹配，不动画面内容：

```bash
# 1) 逐段测平均亮度与色温倾向
ffmpeg -ss <段起点> -t 10 -i in.mp4 -vf "signalstats,metadata=print:key=lavfi.signalstats.YAVG" -f null - 2>&1 | grep YAVG

# 2) 以第一段为基准，其余段对齐（单段独立调，交界处用 0.5 秒交叉淡化）
ffmpeg -i in.mp4 -vf "eq=brightness=<-0.04>:saturation=<1.05>,colorbalance=rs=<-0.02>:bs=<0.03>" -c:a copy out.mp4
```

代价：只能调全局亮度/对比/色偏，调不了「阳光方向」，也调不了「有没有晚霞」。**方向错了后期救不回来，只能在 prompt 里锁死。**

> ⚠️ **YAVG 只能当调色的起点，不能当「漂没漂」的判据。** 平均亮度随画面内容变（礁石滩 / 江面 / 桥全景反光率本来就不同），旧版据「逐段 Y 极差 104%」判光照漂移是误判。判漂看三样：**色温 U 值趋势**（段间漂 >6 或单调漂移）、**同类物体目视对比**、**阴影方向**（方向变了才是真换灯位）。U/V 命令：

```bash
ffmpeg -v error -i in.mp4 -vf "fps=1,signalstats,metadata=print:key=lavfi.signalstats.UAVG:file=-" \
  -f null - | grep -o "UAVG=[0-9.]*" | cut -d= -f2 \
  | awk '{s+=$1;n++; if(n%10==0){printf "第%d拍 U=%.1f\n",n/10,s/10; s=0}}'
```

## 二、声轨编排：旁白写进 prompt，让模型自己念

### 问题现象

旁白是后期叠上去的，和成片原生音轨里已经存在的对白撞在一起，两条人声同时说话，既听不清也假。

### 根因

Muse **原生就带中文人声**。实测原片音轨 ASR 直接认出「这桥若能重建，便利万民」「这泥沙混着海水黏得很」——这些是它照着 prompt 里的人物动作自己生成的对白。所以在外面再叠一层旁白，等于往已经有人说话的房间里再塞一个人。

### 解法：三路声源，时间窗隔离

先认清这片子只有三种声音，**同一时刻只准有一路在说**：

| 代号 | 声源 | 是否入画 | 谁来生成 |
|---|---|---|---|
| A | 画外旁白（叙述者） | 不入画 | 模型念 |
| B | 人物对白 | 入画、有口型 | 模型念 |
| C | 环境床（浪、风、脚步、石落水） | — | 模型生成 |

编排规则：

1. **A 和 B 永不同时。** 旁白说完，画面里的人才开口；人物说完，旁白再接。
2. **A 只配空镜、背影、远景、手部特写。** 只要画面里有人正面对着镜头，模型就会让那个人动嘴。
3. **B 必须写清谁在说、说什么、说完什么反应。** 只写「两人交谈」它会自由发挥出长段废话。
4. **每 10 秒最多一句 B**，且不超过 20 字（口型对得准的上限比旁白低得多）。

### 写法：在时间轴里直接标声源

不要另起一段写「本片有旁白」，要把声音**钉在时间点上**：

```
【0-4秒】<画面描述>。【旁白·画外男声】"洛阳江的潮水三日不退，桥基又被掏空。"（画面中无人开口，无口型）
【4-7秒】<画面描述>。此段无人声，只有浪拍礁石。（说完最后一句后立刻停声）
【7-10秒】<画面描述，礁石上的官员转头看向老匠>。【对白·官员】"这桥，还能建吗？"（口型与台词同步）
```

三个括号里的限制是**必须写**的，它们是防冲突的开关：

- `（画面中无人开口，无口型）` —— 旁白段的保险
- `此段无人声，只有浪拍礁石` —— 留白段的保险，防止模型自己加人声
- `（口型与台词同步）` —— 对白段的保险

### 旁白字数：先测再写

每 10 秒能念多少字，必须先测出模型的实际语速上限（见 `references/念稿极限测试.md`）。**10 秒按 ≤36 字写**（实测基础语速 4.0 字/秒，取 90%），留出余量，否则末尾会被截断或糊成一团。

不许用「语速稍快」这种词指望模型配合——这类形容词对它是噪声，字数才是硬约束。

### 后期兜底

- 若模型念得比预期慢、末尾被切：**不要补配旁白**，改成删字，让它一句话讲完。
- **只有在 prompt 里已经写死「此段无人声，只有环境声」的前提下**，才允许外挂旁白。此时原生音轨里没有对白，可以直接叠，或把环境压到 20–30% 再上 sidechain ducking。别直接 `amix` 两路人声（同音量必然打架）；参考实现见项目目录 `洛阳桥-muse/成片/mix_audio.py`（未随技能分发）。
- **一票否决**：原生音轨里已经有对白的片子，绝不外挂旁白——模型会用它自己的对白把整段填满，实测占 40/50 秒，外面再怎么压也压不干净。

## 三、节奏紧凑：按信息密度写，不按秒数写

### 问题现象

50 秒像 90 秒，人物站着看、慢慢推镜、对话两句就没了。

### 根因

旧 prompt 的时间轴是**按秒分格**写的（这 10 秒「站着望向江心」，下 10 秒「侧头开口」），等于给模型发了一张「慢慢来」的许可。它照着格子填，格子松，成片就松。

### 解法一：一拍 = 一个完整动作闭环

每 10 秒必须包含「起 → 变 → 果」三件事，缺一件就是空转：

| 拍 | 起 | 变 | 果 |
|---|---|---|---|
| 潮毁桥基 | 潮头压来 | 浪掏空桥墩断面 | 碎石落水、桥墩塌了半截 |
| 问因 | 官员指向断口 | 老匠伸手抠淤泥 | 泥从指缝挤出、老匠摇头 |
| 募银 | 小舟切入画面 | 白衣女子抬手 | 银锭开始飞 |

只要有一拍只有「起」没有「果」，这段就是注水，删掉或并入相邻拍。

### 解法二：用强制衔接词

在时间轴每一段开头钉一个词，把「等待」这个动作从模型的选项里删掉：

> 立刻 / 话音未落 / 同一秒内 / 话音还在 / 紧接着 / 不等……就

段与段交界处必写：`接上一段的最后一帧，第一个动作已经开始，不许先静止再动。`

### 解法三：按 1.2–1.3 倍速思维写

写 prompt 时假设画面要跑快一点：动作给足、反应给快、眼神停留压到 0.5 秒内。成片如果仍然偏慢，**后期放慢**：

```bash
# 只放慢无对白段（人声段慢放会变调）
ffmpeg -i seg.mp4 -vf "minterpolate=fps=48:mi_mode=mci:mc_mode=aobmc:me_mode=bidir,setpts=1.25*PTS" \
  -af "atempo=0.8" -c:v libx264 -crf 18 slow.mp4
```

这条是**省钱的核心逻辑**：AI 生成按 10 秒一档收费，生成得快等于同样钱买到更多信息；慢放是免费的，1.25 倍慢放等于把 ¥0.20 的素材用成 12.5 秒。反过来「生成得慢、后期加速」才是真亏——加速会丢帧、丢动作细节，还省不下钱。

**限制**：慢放只用于无对白、无口型的动作段。有人说话的段慢放，声音会拖长变调，必须整段不慢放。

### 解法四：删掉这三类镜头

1. 人物凝望远处超过 2 秒
2. 纯空镜推拉（除了开场第一帧和结尾最后一帧，中间不许有）
3. 走路、上船、进门这类位移过程（直接写「已在船上」）

## 四、三条写在一起用（可直接抄的骨架）

```
【风格锚】<画风一句话>；全程无字幕、无水印、无文字、无现代物件。

【光照卡·全片唯一，任何镜头不得偏离】
时段：正午前三刻；色温 5600K 冷白；主光自左前上方 45° 射入，光比 1:4 硬光；
投影短而边缘清晰、统一指向右后方；天空灰白偏冷、云层薄而均匀；水面受光面亮银白、背光面深灰绿。
铁律：全片共用这一套光照，光线方向、强度、色温、云层、阴影长度、曝光逐段完全一致。
禁止：明暗起伏、曝光跳变、色温漂移、天色由冷转暖或由明转暗、光斑游移、晚霞、丁达尔光柱变化。

【0-10秒】立刻，<动作起> → <动作变> → <动作果>（一次完成，不许停）。
  【旁白·画外男声】"<≤36 字，第一个字压在画面第一帧>"（画面中无人开口，无口型）
【10-20秒】话音未落，<下一动作>……
  【对白·<角色>】"<≤20 字>"（口型与台词同步；此段无旁白）
【20-30秒】紧接着，……

一条连续长镜头，全程不切镜，后一段紧接上一段的最后一帧继续，不重演已发生的动作；
人物造型、服装颜色、道具形制与首帧及参考图完全一致；光照条件自始至终不变。
```
