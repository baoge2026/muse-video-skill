# 片型配方：四类片子怎么配参数

用户 2026-11-21 明确的四条产线：**产品 AI 广告 / AI 真人剧 / 知识讲解 / 低龄启蒙**。

这一节给的是**可直接抄的参数组合**，不是理论。每一类都按同一张表：
时长 → 拍数 → 弧线 → 语速 → 机位 → 声轨 → 素材 → 风格锚 → 废镜头 → 验收。

> 所有价格按 2026-11-21 的档位表：10s ¥0.20 / 20s ¥0.40 / 30s ¥0.60 / 40s ¥0.80 / 50s ¥1.00。
> 图按 ¥0.0035/张。

## 一、产品 AI 广告

**默认 30 秒 / 3 拍 / ¥0.60。** 不要默认 50 秒——产品片拖到 50 秒，后面 20 秒一定是重复展示。

三档怎么选：

| 档 | 拍数 | 弧线 | 价格 | 什么时候用 |
|---|---|---|---|---|
| **20s** | 2 | 反转 → 落点 | ¥0.40 | 信息流/开屏，只讲一件事，观众 3 秒内必须被抓住 |
| **30s（默认）** | 3 | 钩子 → 反转 → 落点 | ¥0.60 | 绝大多数产品片。**3 拍不要求「兑现」拍**，钩子→反转→落点 已闭环 |
| 40s | 4 | 钩子 → 反转 → 兑现 → 落点 | ¥0.80 | 产品有两个必须分开讲的卖点 |
| 50s | 5 | + 身份 | ¥1.00 | 品牌片/发布会，且能说出第 5 拍多给观众什么 |

**判据只有一句：删掉这一拍，观众还看得懂吗？看得懂就删。**

> **秒数不必凑 10 的倍数。** 平台自己平均拆段，官方例子是「25 秒拆成 9+8+8」。
> 价格按档收（21–30 秒都是 ¥0.60），所以**档内越短越好**：同价、少注水、出片更快。
> 折叠电动车那条片内容真正需要 25 秒，就填 25 秒，不填 30。
产品片最常见的错误是"卖点太多所以拍长"，正确的做法是"选一个靶心，其余卖点降级成画面证据"。

| 项 | 配置 |
|---|---|
| 拍数 | 3 拍（钩子 → 反转 → 落点）。卖点确实撑得住才 4 拍（加「兑现」） |
| 语速 | 稳 3.6，每拍 26–30 字 |
| 弧线 | 第 1 拍制造疑问、第 2 拍推翻预期、第 3 拍给观点 |
| 机位 | 每拍一句；**相邻两段用同一句机位描述**（边界跳变小） |
| 声轨 | 每段写「持续的男声画外解说，整段不停」，画面里最好没有人正对镜头 |
| 素材 | 首帧 = 第 1 拍分镜；参考图 = 产品定妆 2 张 + 人物定妆 1 张 |
| 风格锚 | `真实广告实拍质感，商业产品片，浅景深、边缘锐利，色彩干净通透，产品配色饱和但不溢出` |
| negative | `字幕, 水印, 文字, logo, 现代建筑, 电线, 多格资产板` |

**废镜头黑名单（产品片专属）**：产品静止摆拍、360° 环绕、缓慢推近、参数特写堆叠、空镜过渡。

**验收**：每拍三个动作；每拍至少一处「手在做」；结尾不复述卖点。

## 二、AI 真人剧

**默认 40 秒 / 4 拍 / ¥0.80。** 这是四类里最容易翻车的一类，因为**对白由"画面里有没有人在说"驱动**。

| 项 | 配置 |
|---|---|
| 拍数 | 4 拍（钩子 → 反转 → 兑现 → 落点）。**不要超过 4 拍**，多人对白越长越容易串 |
| 语速 | 旁白段用稳 3.6；对白段用紧 4.4（对白要更快更自然） |
| 弧线 | 第 1 拍冲突出现、第 2 拍揭露/误会、第 3 拍情绪释放、第 4 拍一句话 |
| **铁律** | **同一时刻只准一路人声**。一段要么全是旁白，要么全是同一个角色的对白 |
| 单次开口 | **≤20 字**（口型同步质量随长度下降） |
| 机位 | 单人镜头为主；写「口型与台词同步」 |
| 素材 | **人物定妆 ×3 必须**（正面/侧面/全身）+ 场景 2 张；首帧必须是实景帧 |
| 风格锚 | `写实电影质感，35mm 胶片颗粒，浅景深，自然光为主，肤色真实不磨皮` |
| negative | `字幕, 水印, 文字, 动漫, 卡通, 夸张表情` |

**为什么容易翻车**：多人同场时模型会让"看起来在说话的人"都动嘴，两路人声撞在一起；
一段里既有旁白又有对白，模型分不清谁先说。

**绕法**：
1. 一段只留一个角色说话，其他人写「没有说话，只是看着他」。
2. 长台词拆成两段：A 说完，下一段 B 接。跨段接话是允许的（实测 1.0→13.6 秒不断字）。
3. 实在要多人对话，**改用「旁白转述」**——把对白改成旁白，成本更低、稳定性高一个量级。

## 三、知识讲解

**默认 30 秒 / 3 拍 / ¥0.60。** 关键认知：**Muse 不会画图表、不会写文字、不会做动画示意。**

| 项 | 配置 |
|---|---|
| 拍数 | 3 拍（钩子=反常识问题 → 反转=真正原因 → 落点=可执行结论） |
| 语速 | 快 4.0，每拍 32–36 字（信息密度最高的片型） |
| 画面 | **只做「具象化类比」**：说"内存不够"就拍塞满的抽屉，不拍示意图 |
| 机位 | 手部特写、物件特写、单一场景；不要多人 |
| 素材 | 道具图 2–3 张（要讲的那个东西）；不需要人物定妆 |
| 风格锚 | `干净实拍质感，柔和顶光，浅色背景，浅景深，桌面俯拍视角` |
| negative | `字幕, 水印, 文字, 图表, 数字, 示意图, 白板` |

**绝对不要写进 prompt 的东西**：`图表`、`数据`、`文字`、`标题`、`公式`、`流程图`。
模型会画成乱码，而且 negative 也压不住——**这些全部后期叠**。

**验收**：每一拍画面都是"一个能看懂的实物动作"，不是抽象画面。

## 四、低龄启蒙（能做什么 / 不能做什么）

**默认 20–30 秒 / 2–3 拍 / ¥0.40–0.60。** 这一类走 **kids 轨**，规则和其它三类完全不同。

| 项 | 配置 |
|---|---|
| 弧线 | **错误 → 后果 → 正确 → 记住**（`--arc kids`）。**不要用反转**——孩子分不清"故意演错的"和"应该做的" |
| 拍数 | 3 拍最常见（错误 / 正确 / 记住）；加「后果」就 4 拍 |
| 语速 | **慢 3.2**（实测"什么都不提"的对照值，不催语速），每拍 18–23 字 |
| 句子 | **一句一个意思，不套从句**。能让孩子跟着念出来 |
| 画面 | **动画绘本风**，主角用拟人化小动物，不用真人小孩 |
| 素材 | 角色定妆 3 张（正面/侧面/全身）+ 场景 1 张 |
| 风格锚 | `儿童绘本动画风格，圆润造型，柔和暖色，粗描边，平涂上色，无恐怖元素` |
| negative | `字幕, 水印, 文字, 写实, 血腥, 恐怖, 火焰, 刀具, 车流` |

**三条安全红线**：
1. **不演真实危险动作**（玩火、玩刀、跑向马路、跟陌生人上车）。用**后果暗示**代替：
   拍"妈妈在门口找不到孩子"，不拍"孩子被带走"。
2. **不用真人小孩**。真人小孩表情容易崩，且涉及儿童形象，用动物角色更稳更安全。
3. **结尾必须是一句能复述的话**，≤20 字，孩子能记住。"记住：不认识的人说带你走，先找老师。"

**验收**：每拍一句；全片没有反转；结尾那句能让孩子原样说出来。

## 五、风格怎么快速切

**风格 = 风格锚 + negative + 画幅 + 光照卡**。切换时只换这四样，脚本卡和闸门不动。

| 要什么感觉 | 风格锚关键词 | negative 必加 | 画幅 |
|---|---|---|---|
| 真实广告 | 实拍质感、浅景深、边缘锐利、色彩干净 | 动漫、插画、多格资产板 | 16:9 / 9:16 |
| 写实电影 | 35mm 颗粒、自然光、肤色真实不磨皮 | 动漫、卡通、夸张表情 | 16:9 |
| 国风写实 | 厚涂油画笔触、东方古典配色、影视级布光 | 现代物件、电线、玻璃幕墙 | 16:9 |
| 儿童绘本 | 圆润造型、粗描边、平涂上色、柔和暖色 | 写实、恐怖、血腥、火焰 | 16:9 / 9:16 |
| 科技感 | 冷调、高对比、金属反光、体积光 | 手写体、复古、纸张质感 | 16:9 |
| 极简白底 | 纯白背景、柔光箱、无投影、产品居中 | 场景、背景杂物、文字 | 1:1 / 16:9 |
| 竖屏口播 | 半身构图、柔和补光、背景虚化 | 全身、多人、字幕 | 9:16 |

**切换操作**：改脚本卡的 `【风格锚】` 一行 → 重跑 `plan_shoot.py`，20 张分镜图会全部按新风格重出（¥0.07）。
**这就是"快速切换"的全部成本**——图便宜，所以可以整批重出；视频不用动，等图定了再拍。

> 光照卡**不要跟着风格一起换**。风格锚管画风，光照卡管光线；两个一起换会让段间色温漂移（已实测的坑）。

## 六、这张表哪些是实测、哪些是判断

**实测（本技能已有数据）**：语速四档、48 字天花板、对白由「画面里有没有人在说」驱动、
跨段接话正常、单次开口 ≤20 字口型更好、相邻段同机位描述边界更小、模型不演时间流逝。

**判断（未做对照）**：四类片子的默认拍数和字数区间、kids 轨不用反转、动画绘本风比真人小孩稳、
"后果暗示代替危险动作"更安全。这些是按机制和常识推的，**第一次做某一类时，先用最便宜的档位试一条（¥0.20–0.40）**，
再决定要不要上 30/40 秒。

**未验证**：`mute_voice` / `script` 两个参数（见 `片型适配与能力边界.md` 第五节）。
如果 `mute_voice` 成立，真人剧和知识讲解这两类应该改成「静音画面 + 后期配音」，稳定性会再上一个台阶。
