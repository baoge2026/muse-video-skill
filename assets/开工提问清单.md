# 开工提问清单（不问清，不许写文案）

**为什么有这一页**：2026-11-21 折叠电动车这条片，我一共废了 3 版文案。
每一次都不是模型的问题，是我在**不知道产品是什么**的情况下先编了故事：

| 我编的 | 事实 | 谁纠正的 |
|---|---|---|
| 折叠后变成「一只手能拎的箱子」 | 靠背压平+车头折倒，扁平一片，四轮着地，没有提手 | 用户（「你还折叠成行李箱了」） |
| 在早高峰机动车道上穿车流 | 四轮电动代步车，不该上机动车道 | 用户 |
| 买家是「给爸妈买的子女」 | 用户要的是「路上开着、回头率高」的产品展示 | 用户 |
| 25 秒写 76 字 | 额度 88 字，可以写满 | 用户（「就那几个台词」） |

**每错一次，就是一轮「改稿 → 重跑闸门 → 重生图 → 重拍」= 15–20 分钟 + ¥0.6–0.9。**
三次 = 50 分钟。**速度问题的根子在这里，不在模型。**

---

## 规矩：这 12 个问题，答案没到手不写第一句台词

问用户，或者从素材里自己核实。**能自己核实的自己核实，核不了的必须问。**

### A 产品本身（决定画面能不能对）

1. **它到底是什么？** 一句话品类（例：四轮折叠座椅电动车）
2. **展开后长什么样？** 颜色、轮子数量、有没有靠背/扶手/车头立柱、脚踏板
3. **折叠/变形后到底变成什么？** 具体动作 + 最终形态 + 尺寸感
   —— **这一条最容易编错，必须看实拍图或让用户描述**
4. **有没有实拍图/视频？** 有几张、分别是什么角度

### B 谁买、在哪用（决定立意和场景）

5. **买家是谁？** 自己用，还是买给别人？年龄、性别、职业
6. **在什么场景用？** 小区/街道/公园/菜市场/景区/写字楼——**能不能上机动车道**
7. **现在他用什么替代？** 走路？共享单车？电动滑板车？——**这就是对比对象**

### C 数字（决定文案可不可信）

8. **至少两个真数据**：续航、重量、承重、折叠后尺寸、充电时间
   —— 一个都没有就说「无可用数据」，文案里就不许出现数字以外的量化词

### D 边界（决定会不会白拍）

9. **要突出什么？** 拉风 / 方便 / 便宜 / 安全 / 给老人用
10. **绝对不要出现什么？** 竞品、特定人群、危险动作、平台违禁内容
11. **投放平台和画幅？** 抖音竖屏 9:16 / 视频号 / 小红书 / 横屏官网
12. **时长上限？** 15 / 25 / 30 秒

## 填进脚本卡的写法

问完之后，在脚本卡头部写死这四块，缺一块 `check_story.py` 直接判错：

```
【产品事实】折叠后：靠背向下压平贴在座垫上，车头立柱向下折倒，两个扶手向内收，
            整车压成扁平一片、高度到膝盖，四个轮子仍然着地；无提手，不可拎起。（来源：实拍图 产品-折叠.jpg）
【产品事实】展开后：四轮，红黑配色，黑色皮质座垫+靠背+两扶手，红色车头立柱。（来源：实拍图 产品-展开.jpg）
【产品事实】红黑配色，四轮着地，可坐。（来源：用户口述）
【买家】城市短途代步的年轻人，通勤/买菜/去地铁站（来源：用户口述）
【场景】非机动车道、人行道、小区、公园；不上机动车道（来源：用户口述）
【真数据】无可用数据 —— 文案不写续航/重量等具体数字
```

**规矩**：
- `【产品事实】` 至少 3 条，每条后面必须带 `（来源：…）`
- `【买家】`、`【场景】` 必填
- `【真数据】` 至少 1 条；没有就写「无可用数据」，**不许编数字**

## 自己核实的优先级

1. 用户给了图 → **先看图**，把形态写进【产品事实】。别跳过这一步。
2. 用户给了链接/文档 → 先读。
3. 都没有 → 问。**一次问完 12 条，不要一条一条挤牙膏。**

> 一次问完，用户答 2 分钟；一条一条问，来回 6 次，半小时没了。
