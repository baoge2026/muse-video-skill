# 脚本卡模板：写文案的唯一入口
# 用法：复制本文件 -> 逐行填 -> 两道闸门
#   python scripts/check_story.py 脚本卡.txt --segs 5 --emit 台词卡.txt
#   python scripts/plan_shoot.py  脚本卡.txt --segs 5 --out 拍摄计划.md
# 规则：一行一拍，| 分隔，5 列；第 6 列可选（角色，默认旁白）。空行和 # 开头的行会被忽略。
#   ｜段号｜作用｜语速档｜台词｜画面（只写镜头里看得见的东西）｜角色（可选）
# 一段要多句（旁白+对白）就在下一行重复同一个段号，作用写 -：
#   2|反转|稳|蔡襄到任第一件事，不是开工，是数潮。|中景，平视，机位固定；蔡襄攥着木尺往水里插；老匠在他身后站住
#   2|-|快|大人，潮水一天来两回。|老匠伸手指着水面；水线沿木尺往上爬；他抬头看蔡襄|老匠
# 作用（drama 轨，默认）：钩子 / 反转 / 兑现 / 身份 / 落点
#   第 1 拍必须「钩子」，最后一拍必须「落点」，中间至少一拍「兑现」，建议一拍「反转」
# 作用（kids 轨，--arc kids）：错误 / 后果 / 正确 / 记住
#   必须同时有「错误」和「正确」；「记住」放最后一拍；不要用反转
# 语速档：慢(3.2字/秒,10秒32字) / 稳(3.6,36) / 快(4.0,40) / 紧(4.4,44) / 极限(4.6,46,已糊音)
#   低龄儿童片用「慢」；产品片用「稳」；只有信息特别密才用「快」及以上
# 字数不用自己数，check_story.py 会数并核对容量。

【一句话承诺】这里填不超过 20 字：因为有了它，你就不用______
【核心冲突】观众现在的麻烦是什么（一句话）
【受众】谁在看（越具体越好：不是"年轻人"，是"早高峰要开 40 分钟车上班的人"）
【语气】用谁的口吻说话（例：一个懂行的朋友，不是广告腔）
【片长】30 秒 / 3 拍
【风格锚】画风与质感（这一句会直接拼进分镜图 prompt，必须写具体）
【光照卡】时段 / 色温K / 主光角度 / 光比 / 投影方向（全片唯一，逐段原样复制）
【人物】男主：年龄、发型、上衣、裤子、鞋（生定妆图用，没有定妆图人物会换脸）
【道具】产品名：颜色、形制、关键结构（生道具图用）

1|钩子|稳|旁白，≤36字，从第一帧就开口，制造疑问，不许介绍产品全貌|动作1（起手，改变一次状态）；动作2（主体变化，这是信息点）；动作3（结果/反应）；景别，机位，有没有运动
2|反转|稳|旁白，≤36字，把第1拍建立的预期推翻|动作1；动作2；动作3；机位一句
3|兑现|稳|旁白，≤36字，给可验证的数字或对比|动作1；动作2；动作3；机位一句
4|身份|稳|旁白，≤36字，谁在用/什么场合/别人怎么看|动作1；动作2；动作3；机位一句
5|落点|稳|旁白，≤36字，给观点或情绪，不复述卖点|动作1；动作2；动作3；机位一句

# ── 画面为什么必须写三个动作 ──
# 一段固定 10 秒。台词 26 字只念 7.2 秒，剩下 2.8 秒如果画面没事做，
# 模型就会自己拿「凝视 / 空镜 / 缓慢推拉 / 走路」把秒数填掉——这就是「50 秒很多废镜头」。
# 所以每拍画面必须写成「动作1；动作2；动作3」三个连续微动作，
# check_story.py 会数带动作的分句，少于 3 个直接判错。
# 同时禁词：静止、空镜、一路、走去、走向、凝视、望向、伫立、缓慢推近、原地、画面不动。

# ── 填完自查（这几条脚本会拦，先自己看一眼省一轮）──
# □ 一句话承诺能不能单独发给人看、他还复述得出来？
# □ 拍数是不是默认 3 拍？往上加，能说出「多这一拍观众多得到什么」吗？
# □ 第 1 拍有没有出现"今天给大家介绍""这款产品"这类开场？
# □ 每一拍画面里，是不是三个连续动作？有没有「静止/空镜/走向」这类空转？
# □ 画面里已经看见的名词，旁白里是不是又念了一遍？
# □ 全片有没有至少两个具体数字/对比？（kids 轨不用）
# □ 最后一拍是不是在复述卖点？
# □ 全片是不是发生在同一个光照窗口里？（跨早晚 = 要换光照卡 = 色温必漂）
# □ 【风格锚】【人物】【道具】填了吗？没填 plan_shoot 会提醒，分镜图会跑偏
