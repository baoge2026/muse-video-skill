# 脚本卡模板：写文案的唯一入口
# 用法：复制本文件 -> 逐行填 -> python scripts/check_story.py 脚本卡.txt --segs 5 --emit 台词卡.txt
# 规则：一行一拍，| 分隔，5 列；第 6 列可选（角色，默认旁白）。空行和 # 开头的行会被忽略。
#   ｜段号｜作用｜语速档｜台词｜画面（只写镜头里看得见的东西）｜角色（可选）
# 一段要多句（旁白+对白）就在下一行重复同一个段号，作用写 -：
#   2|反转|稳|蔡襄到任第一件事，不是开工，是数潮。|中景，平视，机位固定；蔡襄攥着木尺往水里插
#   2|-|快|大人，潮水一天来两回。|老匠伸手指着水面，水线沿木尺往上爬|老匠
# 作用只能是这五个：钩子 / 反转 / 兑现 / 身份 / 落点
#   第 1 拍必须「钩子」，最后一拍必须「落点」，中间至少一拍「兑现」，建议一拍「反转」
# 语速档：稳(3.6字/秒,10秒36字) / 快(4.0,40字) / 紧(4.4,44字) / 极限(4.6,46字,已糊音)
# 字数不用自己数，check_story.py 会数并核对容量。
# 画面：一句机位 + 一个"变"的动作 + 一个物理细节。不许写「展现/体现/彰显/呈现/营造」。

【一句话承诺】这里填不超过 20 字：因为有了它，你就不用______
【核心冲突】观众现在的麻烦是什么（一句话）
【受众】谁在看（越具体越好：不是"年轻人"，是"早高峰要开 40 分钟车上班的人"）
【语气】用谁的口吻说话（例：一个懂行的朋友，不是广告腔）
【片长】50 秒 / 5 拍

1|钩子|稳|旁白，≤36字，从第一帧就开口，制造疑问，不许介绍产品全貌|中景，平视，机位固定在______，跟着______走；______（谁）______（做什么动作），______（什么东西改变了状态），______（一个物理细节）
2|反转|稳|旁白，≤36字，把第1拍建立的预期推翻|近景，______；______（动作），______（物体变了），______（物理细节）
3|兑现|稳|旁白，≤36字，给可验证的数字或对比|______；______；______
4|身份|稳|旁白，≤36字，谁在用/什么场合/别人怎么看|______；______；______
5|落点|稳|旁白，≤36字，给观点或情绪，不复述卖点|______；镜头从______摇到______，停在______

# ── 填完自查（这几条脚本会拦，先自己看一眼省一轮）──
# □ 一句话承诺能不能单独发给人看、他还复述得出来？
# □ 第 1 拍有没有出现"今天给大家介绍""这款产品"这类开场？
# □ 每一拍画面里，有没有东西改变了状态？没有就是一张会呼吸的照片。
# □ 画面里已经看见的名词，旁白里是不是又念了一遍？
# □ 全片有没有至少两个具体数字/对比？
# □ 最后一拍是不是在复述卖点？
# □ 全片是不是发生在同一个光照窗口里？（跨早晚 = 要换光照卡 = 色温必漂）
